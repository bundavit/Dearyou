# Software Testing class project

Case study: DearYou. Topic: Static Testing Techniques. Planned group presentation: five members, 50 minutes.

- [Project plan](PROJECT_PLAN.md): scope, textbook pages, member allocation, proposed outline, examples and rubric.
- [Member 3 draft notes](drafts/speaker-notes-member-3.md): review types and their comparison.
- [Member 4 draft notes](drafts/speaker-notes-member-4.md): review roles and a proposed classroom inspection.

The notes are partial preparation drafts, not a finished presentation. Slides and the other members' scripts remain paused until requested.

The supplied `Software_Testing_Foundations_A_Study_Guide_for_the_Certified_Tester.PDF` is stored beside this file in the personal USB copy and excluded from Git. After a fresh clone, bring that reference separately if needed. The presentation plan and draft notes are selected for the next source commit.

Historical DearYou defects were discovered in live dynamic QA. The class material uses retrospective static walkthroughs; a staged classroom inspection is not a claim that the group previously completed a formal inspection.
